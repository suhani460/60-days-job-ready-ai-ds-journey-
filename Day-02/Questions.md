# Day 2 Python Practice Questions
Q1. Find the Largest of Three Numbers

Write a function find_largest(a, b, c) that returns the largest of three numbers.

Example:

Input:
10
25
15

Output:
Largest number is: 25

Q2. Count Vowels in a String

Write a function count_vowels(text) that counts the total number of vowels (a, e, i, o, u) in a string.

Example:

Input:
Hello World

Output:
Number of vowels: 3
  ------------------------------------------------------------------------------------------------------------------------------------------------------------
Q3. Check Prime Number

Write a function is_prime(num) that checks whether a number is prime or not.

Example 1:

Input:
17

Output:
17 is a Prime Number.

Example 2:

Input:
20

Output:
20 is Not a Prime Number.
  -----------------------------------------------------------------------------------------------------------------------------------------------------------
